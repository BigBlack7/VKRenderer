# VkRenderer

> - A Simple Renderer for Study Vulkan API
> - Build It By MSVC With C++20

## NameFormat

- FileName -> XxXxx
- Class/StructName -> XxXxx
- FunctionName -> XxXxx
- TemporaryVarName -> xxXxx
- MemberVarName -> mXxXx
- StaticVarName -> sXxXx
- ConstantVarName -> kXxXx
- GlobalVarName -> gXxXx
